使用 Cloudflare Tunnel 实现 AList 远程访问

发表于 2026.03.07 更新于 2026.09.14 分类于 教程 阅读次数：
使用 Cloudflare 免费实现 AList 远程访问

最开始只是想让自己的电脑能够被远程访问，后来逐渐开始把一些服务放在本地运行，比如下载工具、文件管理工具等。其中一个很好用的工具就是 AList，它可以把本地磁盘或者各种网盘统一挂载，通过网页来管理文件。

解决的问题

问题是 AList 默认只运行在本地

如果不在电脑旁边，就无法访问。发现可以用 Cloudflare Tunnel 来实现远程访问 AList，怕自己忘了怎么配置的了，就记录下整个配置过程。

整体架构

访问 alist.haozi.space 时，Cloudflare 会通过 Tunnel 转发请求到本地电脑的 5244 端口。这样就实现了远程访问。

准备工作

在开始之前需要准备以下内容：

  1. 一个 Cloudflare 账号
  2. 一个已经接入 Cloudflare 的域名
  3. 一台电脑
  4. 已经运行的 AList 服务
