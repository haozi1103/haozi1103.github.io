一份关于 Windows 11 电脑的 C 盘清理指南

发表于 2026-08-21 更新于 2026-09-05 分类于 工程 ， 软件小记 阅读次数：
Windows 11 的 C 盘清理指南：先诊断后清理，覆盖存储感知、DISM 组件存储、休眠与页面文件、软件缓存、Docker vhdx 压缩和目录迁移，附维护节奏与避坑清单。

急着动手？直接看速查版：电脑C盘清理速查卡，全部命令一条引用到位。

运行方式：本文所有 PowerShell 代码块均建议以管理员身份运行（Win + R 输入 Powershell）。设置类操作为图形界面，无需管理员。

难度标签：🟢 普通（人人可照做）｜🟡 进阶（需理解命令含义）｜🔴 高级（影响系统、谨慎操作）。

一些更改同样适用于 D 盘 E 盘的清理

为什么要写这份指南?

网上的 C 盘清理视频和博客很多，但绝大多数是“通用教程”：把磁盘清理、存储感知、删 Temp 讲一遍就完事。它们有几个共同的问题：

  • 不讲先诊断：每个人的 C 盘大头不一样，有人是 WinSxS 膨胀，有人是 Docker 虚拟磁盘，有人是微信缓存。不先找出大头就照着通用清单清，可能清了半天只释放几百 MB。
  • 不敢给进阶操作：DISM、休眠文件、WSL 磁盘压缩这些真正能释放几个 GB 的操作，要么不讲，要么一笔带过，还经常不给完整的命令。

针对我这台 Windows 11 + Docker Desktop（WSL2）机器，先诊断、后清理，每个操作给出可复制的命令和风险等级，最后用表格记录每次清理的实际效果，方便以后复查。

第一步：先诊断，别急着清

网上教程最大的错误就是上来就清。正确顺序是先知道空间都去哪了。

用 WizTree（免费、NTFS 扫描极快）扫一遍 C 盘，WizTree 相比于 Spaceniffer 来说，内存占用和扫描速度更快，我认为更适合作为 C 盘的诊断工具。

重点看这几个区域：

  • C:\Windows\WinSxS —— 系统组件存储，可能膨胀到 10~20 GB

  • C:\Windows\SoftwareDistribution\Download —— Windows 更新缓存

  • C:\Users\<用户名>\AppData\Local —— 各种软件缓存、Docker 的 vhdx 都在这里

  • C:\hiberfil.sys、C:\pagefile.sys —— 休眠文件与页面文件

第二步：系统级清理（官方支持清理区）

这一层的操作全部是微软官方支持的方式，不碰系统关键文件。

🟢 1. 存储感知

设置 → 系统 → 存储 → 存储感知，开启自动清理，并点击"配置存储感知或立即运行"，把临时文件保留时限设为 0 天，勾选"删除我的应用未在使用的临时文件"，然后点击"立即清理"。

🟢 2. 磁盘清理老面板

新版"清理建议"覆盖范围比老面板小，windows.old、还原点这些还得用老面板。

Win + R 输入 cleanmgr，选中 C 盘，点"清理系统文件"，

勾选：

  • Windows 更新清理（能释放几个 GB）
  • 以前的 Windows 安装（windows.old，需要注意的是：清完就退不回旧版本）
  • 临时文件、缩略图

等待磁盘清理完成即可：

WinSxS 是系统更新组件的存储库，会保留旧版本以便回滚，长期不清理能膨胀到 10 GB 以上。

注意：永远不要手动删 WinSxS 里的文件，必须用官方命令。

🟡 2. 页面文件 pagefile.sys

虚拟内存，一般不建议关闭。如果 C 盘实在紧张，可以调整到合适的大小（具体调整道多大多小得看具体的自己设备），如果你的 D 盘是本地硬盘的话，也可以把它迁移到 D 盘：

Win + R 输入 sysdm.cpl

高级系统设置 → 性能"设置" → 高级 → 虚拟内存"更改"
不推荐完全关闭 C 盘的虚拟内存，可以调整变小（比如 16GB (约16384 MB)-> 8192 MB），但最佳实践依旧是：选择“系统管理的大小”。
这一部分往往不是 C 盘爆满的大头，如果调整的不好反而让你电脑的运行体验变差，适得其反，得不偿失。

这一部分的操作可逆，你可以随时滚回电脑稳定运行时候的 pagefile.sys 的设置。

🟡 4.系统还原点

系统还原点主要备份 Windows 系统状态（系统文件、注册表、驱动和设置），不是个人文件或软件数据备份，大多数普通用户平时用不到。

适合留下系统还原点的人：经常安装软件、驱动、修改系统设置、喜欢折腾电脑，或者没有其他完整备份的人。

可以关闭的人：电脑使用稳定、不怎么改系统，并且更需要释放磁盘空间的人。

🟢 5. 下载文件夹：清理存量 + 迁移增量

下载 文件夹是最容易积灰的地方，每次清理 C 盘都建议先检查。

① 清理存量

将重要文件归档到 D/E 盘对应目录，安装包、失效压缩包、重复文件直接删除。

但清理只能解决“已经有的”，迁移才能解决“以后还会来的”。

④ 其他数据规划

  • 大型软件 / 游戏 / 素材：优先安装到 SSD 分区（比如我的 D 盘），机械硬盘更适合作为归档和备份。
  • 工业软件（SolidWorks、CATIA、MATLAB 等）：建议安装到SSD 分区（比如我的 D 盘），但部分组件仍可能写入 C 盘。
  • Python / Node.js：主程序体积不大，可以默认安装；开发者更需要关注 .venv、pip 缓存、npm 包和 node_modules。
  • Obsidian / 博客 / 项目文件：不要放 C 盘，建议放独立磁盘，并配合 Git、云同步或备份。

⚠️ 删除文件前确认内容。
